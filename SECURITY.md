# Security policy

Please don't report security problems in public issues.

Email **support@saraltechies.com** with the subject "Saral SMS Sync security", or use GitHub's
[private vulnerability reporting](https://github.com/saraltechies/saralsmssync/security/advisories/new).
Include the app version, your Android version and steps to reproduce.

We reply within a few working days and credit reporters in the release notes, unless you'd rather stay anonymous.

Only the latest version is supported with fixes.
